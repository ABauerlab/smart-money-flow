Mockups das telas do sistema Fluxo Dos Mercados
================================================

Dois tipos de arquivo nesta pasta:

1) Mockups conceituais (.html, formato iPhone 390x844)
   00-home.html
   01-dashboard.html
   02-glossario.html
   03-criptoex-acesso.html
   05-criptoex-listas.html                        (redesign no formato "apuração eleitoral")
   06-criptoex-listas-ficha-lider.html             (drill-down do ativo líder)
   07-criptoex-listas-comparativo-semanal.html     (pódio + ranking semanal)
   10-404.html
   Dados fictícios, estilo visual do produto. Servem para explorar direção de design
   antes de mexer no código real.

2) capturas-reais/ (.png)
   Screenshots reais do app rodando (componentes de verdade, não recriação),
   cobrindo as telas que o conjunto conceitual acima não tinha: Dashboard, Glossário,
   tela de acesso, Operação, Enviar e Histórico. Usadas também na seção "Produto em
   ação" da Home.

Abra qualquer .html direto no navegador para visualizar.
